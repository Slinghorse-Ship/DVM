# Mindestaufbewahrung entfernter Bilder

In **Galerie → Entfernte Bilder → Aufbewahrung** können Medienverwalter eine
Mindestfrist von 0 bis 3650 ganzen Tagen speichern. Ohne eigene Wahl gelten
30 Tage. Der Bereich bleibt zunächst eingeklappt; das native Formular ist auch
ohne JavaScript verwendbar.

Die gewählte Regel gilt ausschließlich für künftig entfernte Bilder. Jeder
Entfernungsvorgang speichert seine konkrete Frist unveränderlich. Neue kürzere
oder längere Regeln ändern keine frühere Frist. Auch 0 Tage löscht keine Datei
automatisch und gibt keinen belegten Bildspeicher frei. Das separat bestätigte
[endgültige Löschen](CMS-BILDLOESCHEN-BEDIENUNG.md) ist inzwischen geprüft.

Aktuelle Vereinszuordnung und Medienverwaltungsrechte werden bei jeder Aktion
geprüft. Jede Regel hat eine eigene Version und unveränderliche Historie. Ein
älteres Formular überschreibt keine neuere Wahl; eingegebene Tage bleiben im
kurzen Fehlerformular erhalten. Im JavaScript-Weg erhält die Fehlermeldung
Tastaturfokus. „Aufbewahrung prüfen“ liest den aktuellen Stand; ungespeicherte
Eingaben können im vorhandenen Dialog behalten oder bewusst verworfen werden.

CMS 16 ergänzt ausschließlich zwei neue Tabellen im Installer. Normale
Webzugriffe ändern kein Schema. CMS 15 ohne diese Tabellen behält lesend die
30-Tage-Vorgabe und zeigt kein unbenutzbares Einstellungsformular.

161 reguläre beziehungsweise 162 Fach-/HTTP-/Datenbankverträge mit Browser
prüfen sechs neu angelegte eigene Bilder, feste Fristen bei 0/2/6/30/3650 Tagen,
veraltete echte Datenbanksichten, aktuelle Rollen, Vereinsgrenzen, CSRF und
native Fehlerkorrektur. Jede frühere vollständige Zeile und Primärkennung,
Gesamtzahl, Veröffentlichung, private Bilddatei, Quarantäneplan und
verschlüsselter Nachweis bleibt unverändert.

71 tatsächliche Browserverträge prüfen JavaScript und native Formulare,
320/390/820 Pixel, 200 % Zoom, lesbare Schrift und mindestens 44-Pixel-Ziele,
Tastatur, korrigierbare Grenzen, lokale Konflikte und den vorhandenen
Verwerfen-Dialog. Exakt zwei neue eigene Regeln werden gespeichert; ein
weiterer veralteter Antrag wird abgewiesen. Kein externer Versand.

20 betroffene native Suiten einschließlich tatsächlichem Produktionscontroller,
Rechteprüfung, aktueller globaler Verwendung, Dateiwiederaufnahme und Quoten
bestehen. Installerupgrade und verschlüsselte Wiederherstellung erhalten auch
wirkliche frühere Quarantänezustände und die vollständige Regelhistorie.
