# KoSIT-Laufzeit einrichten

Die aktuelle Anleitung für eigene Installationen steht unter
[Zusatzlaufzeiten: OCR, KoSIT und ERiC](../ZUSATZLAUFZEITEN.md).
Sie beschreibt Paketbezug, private Ablage, Konfiguration und Prüfung.

Frühere hostingbezogene Einzelprüfungen unter diesem Dateinamen sind über Git
nachvollziehbar. Ihre temporären Pfade und damaligen Systembibliotheken sind
keine allgemeine Installationsanleitung und werden nicht auf neue Systeme
übertragen.
