# Nicht zugeordnete Videos privat wiederherstellen

Im eigenen Reel-Entwurf **Videofassungen → Videospeicher → Nicht zugeordnete
Videodateien** öffnen. **Speicher prüfen** öffnet ein eigenes Fenster. Bei der
gewünschten Datei **Datei prüfen**, anschließend **Wiederherstellen** wählen.
Videonamen angeben und **Private Videofassung speichern** drücken. Titel,
formatierter Text und Speicherkennung des offenen Beitrags bleiben erhalten.
Das funktioniert auf Deutsch und Englisch sowie mit und ohne JavaScript.

Gespeichert wird eine neue private Kopie einer vollständigen, mindestens eine
Stunde alten eigenen MP4-Datei. Die ursprüngliche Datei bleibt erhalten. Es
entstehen keine Freigabe, Veröffentlichung, Rechteerklärung oder Anbieterjobs.
Die neue Fassung muss vor einer Veröffentlichung gesondert geprüft und
freigegeben werden. Die bestehende Videoquote gilt auch für diese Kopie.

**Ursprüngliche Wiederherstellung prüfen** liest genau die ursprüngliche
Dateiauswahl, ihren Namen und Beitrag. Die Prüfung kopiert keine Datei. Bei
verlorener Antwort bleibt die ursprüngliche Anfrage für **Ursprüngliche
Wiederherstellung erneut versuchen** erhalten. Es gibt keine automatische
Wiederholung und keine zweite Kopie derselben ursprünglichen Datei.

**Wiederherstellung begonnen, noch nicht abgeschlossen** bezeichnet eine dauerhaft
begonnene Absicht. Eine vorbereitete Kopie kann bereits vorhanden sein. Zum
Abschluss **Wiederherstellung fortsetzen** verwenden. Eine vollständige Kopie
muss bytegleich sein; eine Teilkopie wird nur nach Prüfung ihres vorhandenen
Präfixes ergänzt. Abweichende Dateien bleiben erhalten. Schließen bricht einen
bereits begonnenen Vorgang nicht ab.

Wurde der Beitrag zwischenzeitlich geändert, bleibt die eingereichte Fassung
im Formular erhalten. **Fortsetzung zum aktuellen Beitragsstand vorbereiten**
wählt bewusst den aktuellen Beitrags- und Vereinsstand. Die Vorbereitung
verändert keine Datei. Erst anschließend wird ausdrücklich fortgesetzt. Der
Name einer bereits begonnenen Wiederherstellung bleibt unveränderlich. Im
Ergebnis steht die tatsächlich gespeicherte Beitragsfassung; eine spätere
Fortsetzung wird nicht als Bestätigung einer früheren Beitragsfassung ausgegeben.

Ohne JavaScript öffnen Fehlerkorrektur und Ergebnis ein eigenes Fenster. Auch
zu lange oder unpassende Namen bleiben zur Korrektur erhalten. Quelle,
Dateinachweis, eingereichte Version und Seitenzeiger bleiben gebunden. Ein
negatives Prüfergebnis ersetzt keine frühere positive Bestätigung. Aktuelle
Leserechte und Verwaltungsrechte sind für private Wiederherstellungen erforderlich;
für neue Kopien und Fortsetzungen zusätzlich Bearbeitungsrechte.

Unter **Video-Wiederherstellungen → Vorgänge prüfen** stehen sechs ursprüngliche
Vorgänge je Seite. **Gespeichert → Ergebnis öffnen** zeigt das Originalergebnis,
**Offen → Fortsetzung öffnen** die noch offene Kopie. **Weitere Vorgänge** und
**Erste Vorgänge** führen durch die ursprünglichen Zuordnungen. Zeitangaben
verwenden Europe/Berlin mit maschinenlesbarem ursprünglichem UTC-Zeitpunkt.
**Ursprünglichen Wiederherstellungsvorgang öffnen** führt auch aus einem
Ergebnisfenster zur genauen Quelle zurück. Die Ansicht spielt keine Videos ab.

Späteres Archivieren oder endgültiges Löschen ändert keinen früheren
Speichernachweis. Das Ergebnis zeigt diesen späteren Dateizustand getrennt an.
Eine alte Anfrage legt eine inzwischen bewusst gelöschte Kopie nicht erneut an.
**Archiv öffnen** führt zum aktuellen ursprünglichen Dateizustand.

Die vollständige Erstinstallation enthält alle nötigen Tabellen automatisch.
Fachaufrufe legen keine Tabellen an; es gibt keine gesonderten
Migrationsdownloads. Diese Bedienungsänderung erfordert keine erneute vollständige
Installations-, Paketupgrade- oder Betriebswiederherstellungsrunde.
Aktuelle Nachweise und verbleibende Release-Arbeit stehen im Umsetzungsregister.
Die endgültige Behandlung unbekannter Originaldateien bleibt ein eigener Ablauf.

## English

Open **Video storage → Unassigned video files → Check storage**, then **Check file
→ Recover**. Enter a video name and choose **Save private video version**.
Inspection, recovery and correction use separate windows; the unsaved post stays
open. The original file is retained, and the copy is neither approved nor published.

After an interruption, use **Check original recovery**. A pending recovery can be
continued without another copy. If the post has changed, explicitly choose
**Prepare continuation with the current post revision**, then continue. The name
of an accepted original plan stays fixed. The result shows the revision actually
stored and its later archive or deletion state. Repeating an old request never
recreates a deliberately deleted copy. Current management and read permission
are required; creating or continuing a copy also requires edit permission.
