# Verbindlicher Website- und Plattformumfang

Die integrierte Website umfasst die folgenden Fachbereiche. Neue Installationen
verwenden die eigene Anwendung und ihre dokumentierten Modulverträge.

Neue Installationen erhalten neue Inhalte. Ein Import alter Websitebestände,
Konten, Empfänger oder Tokens ist nicht beauftragt. Das Kulturhus-Design bleibt
als Vorlage erhalten; weitere moderne Websitevorlagen sind auswählbar.
Bestehende native Originale und Fachregeln bleiben geschützt.

| Bereich | Verbindlicher Umfang |
| --- | --- |
| Inhalte und Navigation | Seiten, eigene Adressen, Menü, Hierarchie, Kopien, Archiv und geschützte Rückholung |
| Gestaltung | Wählbare Vorlagen, getrennte Vereinsgestaltung, bearbeitbare Abschnitte und Vorschau |
| Beiträge und Veranstaltungen | Entwurf, Freigabe, Planung, Veröffentlichung, Programm, Tickets und vorhandene Eventbrite-Zuordnung |
| Medien und Versionen | Originale, Varianten, Rechte-/Creditangaben, Verwendungsnachweis und geschützter Lebenszyklus |
| Öffentliche Wege | Formulare, Suchmaschinensteuerung, Sitemap sowie benötigte RSS-/ICS-/JSON-Ausgaben |
| Konten und Rechte | Native Anmeldung, MFA, Reset, Sitzungen und aktuelle Vereins-/Objektrechte |
| Plattform | Die unter P-01 bis P-25 dokumentierten eigenen Verträge einschließlich Sprache, API, Erweiterungen und Betrieb |
| Auslieferung | PHP-/MySQL-Installer, private Konfiguration, optionale Laufzeiten und verständliche Hosting-Zeitpläne |
| Bedienung | Vollständige Fachwege, Touch, Tastatur, schmale Ansichten, Zoom sowie Fehler und Wiederaufnahme |

Die technische Implementierung und ihre tatsächliche Bedienung müssen gemeinsam
geprüft sein. Ein Komponentenlauf oder eine Statuszeile ersetzt keine endgültige
Release-Abnahme. Geräte, aktuelle Anbieterergebnisse und benannte Finanzrestfälle
bleiben gesondert nachzuweisen.
